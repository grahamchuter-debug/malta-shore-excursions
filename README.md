# Malta Shore Excursions

Premium World 2.0 cruise destination site for [maltashoreexcursion.com](https://maltashoreexcursion.com).

## Stack

- Next.js 16 static export
- Tailwind CSS v4
- Cloudflare Pages (`wrangler`)

## Commands

```bash
npm install
npm run download:images
npm run dev
npm run build
npm run check-links
npm run seo-qa
```

## Deploy

```bash
npm run pages:deploy
```

Cloudflare Pages project name: `malta-shore-excursions`  
Canonical domain: `maltashoreexcursion.com` (singular)
